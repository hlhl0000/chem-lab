엘니뇨 어부 버티기 게임

학급 전체가 태평양 서쪽·동쪽 마을의 어부가 되어 24턴을 버팁니다. 교실 TV는 교사가, 휴대폰은 학생이 엽니다. 인터넷 연결이 필요합니다.

교사교실 TV에서 방 만들기

  1. 아래 단추로 교사 화면을 엽니다.
  2. 교사 비밀번호를 넣습니다(그 PC에서 처음 한 번만).
  3. PIN 4~8자리를 정하고 [방 만들기]를 누릅니다.
  4. 화면의 방 코드 4자리를 학생에게 알려 줍니다.
  5. 모두 들어오면 [연습] 또는 [실전]을 누릅니다.

PIN은 교사 화면이 닫혔을 때 다른 PC에서 다시 들어가는 열쇠입니다.
