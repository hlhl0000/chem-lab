# 화학 탐구실 — 사이트 구조 안내

자바실험실처럼 **대문 페이지에서 여러 시뮬레이션으로 이동하는 사이트**의 최소 골격입니다.
프레임워크·빌드 도구 없이 순수 HTML/CSS/JS만 씁니다.

> **새 시뮬레이션을 만들거나 고치기 전에 `시뮬레이션_작업매뉴얼_v1.0.md` 를 먼저 읽으세요.**
> 디자인 기준(옛 `디자인매뉴얼_v4.0.md`)과 검토 파이프라인, 그리고 지금까지 실제로 밟은
> 함정 9건이 **한 문서로 통합**되어 있습니다. 작업 기준은 그 문서가 유일한 출처입니다.

## 폴더 구조

```
화학탐구실/
├── index.html          ← 대문. 카드 목록·검색·분류 필터
├── sims.js             ← ★ 시뮬레이션 카탈로그 (여기만 고치면 목록이 바뀜)
├── shared/
│   ├── style.css       ← 사이트 공통 디자인 (색·버튼·카드·표·슬라이더)
│   └── nav.js          ← 모든 페이지 위쪽 이동 메뉴를 자동 삽입
├── gas/                ← 기체: 압력·부피·온도 (기존)
├── universe/           ← 통합과학: 우주 초기 원소의 생성 (단일 파일형)
├── vapor/              ← Ⅱ 용액: 증기 압력 내림과 총괄성
├── osmosis/            ← Ⅱ 용액: 삼투와 삼투압
├── entropy/            ← Ⅲ 자발성: 엔트로피 — 경우의 수 세기
├── rate/               ← Ⅳ 반응 속도: 온도와 반응 속도 · 활성화 에너지
├── gaslaws/            ← ★ 기체 법칙 4탭 (보일·샤를·아보가드로·이상기체방정식)
├── press/              ← ★ 유압 프레스 도전 게임 (PV=nRT + 파스칼 원리)
├── liquid/             ← ★ 액체의 끓음 — 실제 액체 4종 3D 관찰 + 가열 곡선
├── mineral/            ← ★ 광물의 결정 — 거시 관찰에서 입자 모형까지
├── .nojekyll           ← GitHub가 파일을 재가공하지 않게 막는 빈 파일
├── .gitignore
├── 시뮬레이션_작업매뉴얼_v1.0.md  ← ★ 작업 기준 통합본 (디자인 + 검토 + 함정)
├── 디자인매뉴얼_v4.0.md            ← 위 매뉴얼 2부에 흡수됨. 참고용으로 남겨 둠
└── README.md
```

핵심은 **`sims.js` 한 곳이 사이트 전체의 목차 역할**을 한다는 점입니다.
대문의 카드도, 각 시뮬레이션 페이지 상단의 "다른 시뮬레이션으로 이동" 메뉴도
모두 이 배열을 읽어서 자동으로 만들어집니다.

현재 `sims.js` 에 **16개 항목**이 등록되어 있고 그중 **10개가 `ready: true`** 입니다.

## 새 시뮬레이션 추가하는 법 (3단계)

1. 폴더를 만든다 — 예: `titration/`
2. 그 안에 `index.html`을 만든다. `gas/index.html`을 복사해서 고치는 게 가장 빠릅니다.
   페이지 맨 아래 세 줄은 그대로 두고 `data-current`만 새 id로 바꾸세요.

   ```html
   <script src="../sims.js"></script>
   <script src="../shared/nav.js" data-base=".." data-current="titration"></script>
   <script src="sim.js"></script>
   ```

3. `sims.js`의 해당 항목에서 `ready: false`를 `true`로 바꾼다.

끝입니다. 대문 카드와 이동 메뉴에 자동으로 나타납니다.

## 두 가지 페이지 형태

이 사이트에는 구조가 다른 두 종류의 시뮬레이션 페이지가 있습니다.

| 형태 | 예 | 상단 이동 메뉴 |
|---|---|---|
| **표준형** — HTML + `sim.js` 분리, 공통 CSS 사용 | `gas/` `vapor/` `osmosis/` `entropy/` `rate/` `gaslaws/` `press/` `liquid/` `mineral/` | `shared/nav.js`가 자동 삽입 |
| **단일 파일형** — CSS·JS가 한 파일 안에 있고 화면 전체(100vh)를 씀 | `universe/` | 자체 헤더 안의 `← 전체 목록` 링크 |

`universe/`처럼 전체화면을 쓰는 시뮬레이션에 `shared/nav.js`를 붙이면
네비게이션 바 높이만큼 화면이 밀려 아래가 잘립니다. 그래서 이런 페이지는
**공통 네비를 쓰지 않고**, 원래 헤더에 대문으로 돌아가는 링크 한 개만 넣습니다.

`universe/index.html`에서 사이트 통합을 위해 추가한 부분은 두 군데뿐이고
둘 다 주석으로 표시해 뒀습니다 — 헤더의 `<a id="backLink">` 한 줄과,
`</style>` 바로 위의 "사이트 통합용 추가 스타일" 블록입니다.
**이 두 곳만 지우면 원본 파일로 정확히 되돌아갑니다.**

새 시뮬레이션은 되도록 표준형으로 만드는 것을 권합니다.

## 디자인을 한 번에 바꾸려면

`shared/style.css` 맨 위 `:root` 안의 색깔 값만 고치면 사이트 전체에 반영됩니다.
**개별 페이지에서 `:root` 를 다시 선언하면 안 됩니다.**

```css
--accent:#2563eb;   /* 이 한 줄로 버튼·링크·강조색이 전부 바뀝니다 */
```

## 로컬에서 보기

`index.html`을 더블클릭하면 대부분의 환경에서 그대로 열립니다.
(`fetch`나 ES 모듈을 쓰지 않고 일반 `<script src>`만 쓴 이유입니다.)

브라우저 보안 설정 때문에 안 열린다면 VS Code의 **Live Server** 확장을 설치하고
`index.html` 우클릭 → *Open with Live Server* 를 쓰세요.

## 인터넷에 올리기 (GitHub Pages)

1. GitHub에서 **Public** 저장소를 만든다 — 예: `chem-lab`
2. 이 `화학탐구실` 폴더 **안의 내용물**을 저장소 최상단에 올린다
   (폴더째 올리면 주소에 `/화학탐구실/`이 한 겹 더 붙습니다)
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save
4. 1~2분 뒤 `https://<아이디>.github.io/chem-lab/` 에서 열립니다

학생에게는 이 주소를 QR코드로 배포하면 편합니다.
개별 시뮬레이션 주소는 `https://<아이디>.github.io/chem-lab/gas/` 형태입니다.

> ⚠ **이 폴더의 내용물이 곧 공개 저장소의 최상단입니다.**
> 학생 이름·평가 자료·인수인계 문서 등 공개하면 안 되는 파일을 이 폴더에 두지 마세요.
> 인수인계 문서는 **한 단계 위 폴더**(`[AI] 시뮬레이션 사이트/`)에 둡니다.

### 실측 중 발견해 고친 것 (물질의 세 가지 상태 4종)

숫자 검증만으로는 **전부 통과했는데** 스크린샷을 눈으로 보고서야 잡은 것들입니다.

1. **`gaslaws/` 피스톤이 평형에서 ±17.6 % 로 출렁이던 문제** — 위치 제어가 압력 센서보다 빨랐습니다.
   평균만 재는 수치 검증은 통과했습니다. 비례 제어(`W × P측정/P목표`)로 교체.
2. **샤를 외삽이 −296 ℃ 로 나오던 문제** — 입자에 부피를 준 모형이라 실제로는 **실제 기체**였습니다.
   벽 충돌을 점 입자로 바꾸어 이상 기체 모형으로 재작성 → 정확히 **−273.0 ℃**.
3. **`press/` 유압유가 끊긴 두 기둥처럼 보이던 문제** — 파스칼 원리(압력이 유체 전체에 전달됨)와
   정면으로 어긋나는 그림이었습니다. **U자관**으로 다시 그렸습니다.
4. **`press/` 레벨 4가 넓은 피스톤에서는 도달 불가능하던 문제** — 실시간 안내 문구를 띄워
   "지금 고른 A₂ 로는 닿을 수 없습니다" 를 알려 주도록 수정.
5. **`mineral/` 표본이 회전할 때 조명이 같이 돌아 어둡던 문제** — 법선은 물체 좌표, 조명은 세계 좌표였습니다.
   (GLSL ES 1.0에는 `transpose()` 가 없어 역회전 행렬을 직접 만들어야 합니다.)
6. **`mineral/` 캔버스가 `display:none` 일 때 음수 반지름으로 그려지던 문제** — 폭이 40px 미만이면 건너뛰도록 수정.
7. **휴대폰 폭에서 `gaslaws/` 안내판 글자가 상자를 넘치던 문제** — `ctx.measureText()` 로 재어
   좁을 때는 짧은 문구로 바꾸도록 수정.
8. **⚠ `shared/style.css` 의 슬라이더 색이 사이트 전체에서 한 번도 적용되지 않던 결함** —
   `.rng-temp::-webkit-slider-thumb` (특이도 0,1,0) 가
   `input[type=range]::-webkit-slider-thumb` (0,1,1) 에 지고 있었습니다.
   선택자 앞에 `input[type=range]` 를 붙여 해결했습니다.
   **이 수정은 `vapor/` `osmosis/` `entropy/` `rate/` 에도 함께 적용됩니다** —
   그동안 색 구분이 없던 슬라이더들이 이제 온도=붉은색, 부피=푸른색 등으로 구분됩니다.
   해당 4종을 다시 열어 색이 의도대로 보이는지 확인해 주세요.
